# 截图

把界面截图放在本目录，文件名与根目录 `README.md` 中引用的保持一致：

| 文件名 | 界面 | 建议内容 |
| --- | --- | --- |
| `library.png` | 书架 | 双书架页签、分组封面叠放、书籍网格 |
| `reader-comic.png` | 条漫阅读 | 上下连续模式，页面铺满 |
| `reader-text.png` | 文字阅读 | 控制栏展开，可见字号 / 行距 / 纸张 |
| `settings.png` | 设置 | 阅读与排版设置页 |

建议：

- 手机直接截屏导出的 PNG，宽度约 1080px 即可，不需要额外压缩
- 四张用同一台设备、同一套主题，横向排列时观感更统一
- 深色模式好看的话，可以再多截一张 `library-dark.png`

放好之后，打开根目录的 `README.md`，找到「截图」小节，把包着 `<p align="center">` 的那段 HTML 注释去掉即可显示。
